## 🚀 Deployment & Local Setup

### Deploy to Cloudflare Pages (Recommended)
1. Fork or push this repository to GitHub.
2. Log into the **Cloudflare Dashboard** -> **Workers & Pages**.
3. Select **Connect to Git** and pick `velqor-systems`.
4. Leave build settings default (`Framework: None`, `Build output directory: /`).
5. Click **Save and Deploy**.

### Local Preview
Open `index.html` directly in any standards-compliant browser.
